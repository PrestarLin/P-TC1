# P-TC1 斐讯TC1智能排插固件

基于斐讯TC1排插（A1版本）的第三方固件，无需服务器即可实现完整智能控制。

感谢原作者 [zogodo](https://github.com/zogodo/zTC1) 的代码基础，以及 [a2633063](https://github.com/a2633063/zTC1) 提供的烧录说明。

![web](./doc/Phicomm_TC1.png)

## 功能一览

### 基础功能
- [x] 物理按键控制总开关
- [x] 独立控制6个插口通断
- [x] Web后台实时功率/功耗显示
- [x] 定时任务（支持多设备、多时段、星期几）
- [x] OTA在线升级
- [x] MQTT接入HomeAssistant

### 智能功能
- [x] **按键自定义**：短按/长按可配置15种功能（切换插口、指示灯、童锁、配网、重启等）
- [x] **童锁**：开启后屏蔽所有物理按键，防止误触
- [x] **今日/昨日/总耗电量**传感器（MQTT自动上报）
- [x] **可调上报频率**（默认2秒）
- [x] **LED开关**：可关闭指示灯（系统自检/错误灯仍工作）
- [x] **插座名称自定义**：后台可改，自动同步到HA
- [x] **WiFi断连处理**：可配置超时后自动关闭热点或重启
- [x] **WiFi RSSI传感器**：信号强度实时上报
- [x] **MQTT状态指示**：Web界面显示MQTT/WiFi连接状态

### 开机防呆（救命逻辑）
- **按住按钮开机，松开** → 进入配网热点 `TC1-AP-xxxx`
- **按住按钮开机，持续10秒不松** → 恢复出厂设置
- 此逻辑**绕过童锁**，防止童锁+WiFi故障导致插座无法恢复

## 固件获取

本项目使用 **GitHub Actions 云端编译**，无需本地搭建编译环境。

### 使用已编译好的固件
前往 [Releases](https://github.com/PrestarLin/P-TC1/releases) 页面下载：
- `ota.bin` — OTA升级固件（通过Web后台上传）
- `TC1@MK3031@moc.all.bin` — 全量固件（含Bootloader，需烧录器写入）

### 自行编译
1. Fork本仓库
2. 推送代码到 `dev` 或 `master` 分支，GitHub Actions 自动编译
3. 编译产物在 Actions 的 Artifacts 中下载

## 首次使用

1. 插上排插，按住按钮开机（或上电前按住）
2. 松开后进入配网热点 `TC1-AP-xxxx`（xxxx为MAC后四位）
3. 连接热点，浏览器访问 `http://192.168.0.1`
4. 在Web界面配置WiFi、MQTT等

## 默认配置

| 配置项 | 默认值 |
|--------|--------|
| MQTT地址 | `mqtt.iot` |
| MQTT端口 | `1883` |
| MQTT用户/密码 | `iotserv` / `iotserv` |
| 本地Web端口 | `80` |
| 总开关默认状态 | 关 |
| 插口1-6默认状态 | 开/开/开/开/关/关 |
| 上报频率 | 2秒 |
| 按键短按(默认) | 总开关 |
| 按键长按5秒 | 进入配网热点 |
| 按键长按10秒 | 恢复出厂设置 |
